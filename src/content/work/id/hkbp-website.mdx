## Ringkasan

Saya membangun website ini sebagai kontribusi pribadi untuk gereja. Selain melayani kebutuhan komunitas, proyek ini juga menjadi studi kasus nyata untuk workflow full-stack berbantuan AI.

### Tantangan

Masalah umum komunikasi komunitas yang perlu diselesaikan:
- Pengumuman tersebar di banyak chat
- PDF warta sulit ditemukan
- Jadwal kegiatan tidak terpusat
- Informasi publik tidak mudah diakses
- Admin butuh alur manajemen konten yang sederhana

### Solusi

Platform terpusat untuk:
- Menyediakan website publik
- Mempublikasikan jadwal dan event
- Mengelola pengumuman
- Upload dan tampilkan PDF warta
- Merapikan organisasi konten
- Menyediakan workflow yang ramah admin
