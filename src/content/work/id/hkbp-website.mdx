## Ringkasan

Saya membangun website ini sebagai kontribusi pribadi untuk gereja. Proyek ini juga jadi studi kasus nyata untuk membangun produk full-stack dengan workflow engineering berbantuan AI.

Yang disediakan:

- website publik untuk jemaat dan calon pengunjung
- workflow admin yang sederhana untuk mengelola konten
- publikasi PDF warta mingguan (arsip rapi)
- informasi event dan jadwal yang terpusat

### Tantangan

Komunikasi komunitas sering tersebar di banyak channel dan file.

Masalah yang paling sering muncul:

- pengumuman tersebar di banyak chat
- PDF warta sulit ditemukan dan tidak searchable
- jadwal kegiatan tidak terpusat
- informasi publik tidak mudah diakses
- admin butuh alur manajemen konten yang mudah untuk non-teknis

### Solusi

Platform terpusat yang:

- menyajikan halaman publik yang jelas dan konsisten
- mempublikasikan pengumuman dan jadwal dengan rapi
- upload dan tampilkan PDF warta dengan pengalaman baca yang nyaman
- fokus ke workflow admin yang low-friction

## Pendekatan (High Level)

Prioritas implementasi:

- cepat ship v1 yang bisa dipakai
- mudah dirawat oleh tim gereja
- performa bagus untuk pengguna mobile

## Arsitektur (Simplified)

```text
User Browser
→ Cloudflare (DNS/CDN sesuai kebutuhan)
→ Hosting aplikasi (containerized)
→ Web app (React) + API (Go)
→ MySQL + object storage (R2) untuk file
```
